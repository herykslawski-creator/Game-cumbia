# Tecladista Hero

Jogo estilo Guitar Hero de cumbia, com o tema do Campeonato de Tecladistas de Cumbia.

- `tecladista-hero.html`: código-fonte do Artifact publicado no Claude (com placar online).
- `index.html`: a mesma página como documento completo, para abrir localmente ou no GitHub Pages (placar fica salvo só no navegador).

Controles: `D F J K L` (ou `1`–`5`) tocam as teclas, `Espaço` ativa o Modo Sonidero, `Esc` pausa. No celular, toque nas teclas.

Todas as músicas são composições originais sintetizadas ao vivo com Web Audio.
