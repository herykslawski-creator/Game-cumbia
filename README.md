# Cumbia Hero

Jogo de ritmo estilo Guitar Hero de cumbia, com visual pixel art, inspirado no Campeonato de Tecladistas de Cumbia.

- `tecladista-hero.html`: código-fonte do Artifact publicado no Claude (com placar online).
- `index.html`: a mesma página como documento completo, para abrir localmente ou no GitHub Pages (placar fica salvo só no navegador).

## Setlist
1. **Cumbia Hero** — tema original do jogo
2. **La Cucaracha** — tradicional mexicana
3. **Gaita del Río** — composição original no estilo da cumbia de gaita colombiana
4. **El Cóndor Pasa** — Daniel Alomía Robles, 1913 (melancólica)
5. **El Rey de la Montaña** — Edvard Grieg, 1875 (chefão final, acelera a cada round)

Melodias de terceiros em domínio público, arranjadas em cumbia. Tudo é sintetizado ao vivo com Web Audio.

## Como jogar
- A música toca inteira sempre; a dificuldade só muda quantas notas viram botões: Fácil (3 teclas), Médio (4), Difícil (5).
- `D F J K L` (ou `1`–`5`) tocam; no celular, toque nas teclas.
- Notas longas: segure e tremule (dedo de um lado pro outro, mouse ou `←` `→`) para entortar o som e encher o Sonidero nas notas douradas.
- `Espaço` ou o botão ¡SONIDERO! ativam o Modo Sonidero (pontos em dobro). `Esc` pausa.
